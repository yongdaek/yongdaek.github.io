Goals

  • To discover new attacks in emerging systems.
  • The main objective is to learn how to think like an adversary.
  • Review various ingenious attacks and discuss why and how such attacks were possible.
  • Students who take this course will be able to analyze the security of practical systems.

No Goals

  • In-depth study of OS / Software / Network security and Cryptography.
  • Hands-on hacking tutorials on Android, Windows, embedded systems, etc.

Textbook

  • Required: Papers!
  • Optional
    • Handbook of Applied Cryptography by Alfred J. Menezes, Paul C. Van Oorschot, Scott A. Vanstone, CRC Press, 1996. Available on-line at http://www.cacr.math.uwaterloo.ca/hac/
    • Security Engineering by Ross Anderson. Available on-line at https://www.cl.cam.ac.uk/~rja14/book.html

Course Content

  • Overview: Introduction; Attack Model, Security Economics, Legal Issues, Ethics; Cryptography and Key Management
  • Frequent mistakes: User Interface and Psychological Failures; Software Engineering Failures and Malpractices; Cryptographic Failures
  • Case Studies: Medical Device, Blockchain, Privacy, Machine Learning, Autonomous Driving, Drone, Cellular Network, Metaverse, LLM, Robot, Satellite, and anything else (up to you!)
